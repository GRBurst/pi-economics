### Cache (Claude models)

Per session branch (warming requests refresh the cache but are no row): a request's cache write is **new context** (growth: the context added since the previous request, written once whatever happens) plus a **rewrite**, the **miss**: tokens of the prefix the previous request left in the cache (cacheRead + cacheWrite) that this one did not read. Only a miss is avoidable. Cause of a miss, the first that holds: ttl (the gap outlived the TTL in force; a gap runs from the latest send before the request to its send, ts − durationMs: a long response does not age the prefix it read; TTL: 5 min, 1 h for a main session in a mainCacheTtl 1h arm or after a 1 h write), fold (the prompt fell below 80% of the previous request's), model (the model changed), prefix (the system prompt, a prompt section or the tool list changed: the line's systemHash differs from the last one before it in the branch), other (a change of the prefix inside the TTL that the meter lines do not show: a small fold or mask, an injected agent message, a system change on lines without a systemHash; it is a real cost, not a bookkeeping residue, but its reason is not in the log). $ = API-eq at each line's input price p: a write is 1.25 p (2.0 p for a 1 h write), a read 0.1 p; a miss costs the premium of writing over reading.

### Fold ledger (Claude models)

Per detected fold (a non-warming request whose prompt, input + cacheRead + cacheWrite, fell below 80% of the previous one's): R = tokens removed; K ≈ the first request's cacheWrite minus the session's typical write (median of its non-first, non-fold, non-cold turns), 0 for a fold after a cold gap; n = requests after the fold until the session ends or the next cold gap (≥ 5 min, ≥ 60 min in a mainCacheTtl 1h arm; warming counts); r and w = the model's cache read and write price per token: 0.1 × the input price recovered from the lines' cost for a read, 1.25 × for a 5-minute write and 2.0 × for a 1 h write (a write is a 1 h one in a mainCacheTtl 1h arm's main session, or by the line's own cacheWrite1h). **Net = n·R·r − K·(w − r)** = cache-read $ saved − rewrite $ paid. Counterfactual only: it assumes the fold changed nothing else (output, later tool use, task path) and that an unfolded prompt would have kept being read at r; folds overlap in time but each is valued alone.
